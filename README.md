## Features
- rendering scene trees
- loading objects from .obj
- Phong lightning
- handling textures and normal maps
- basic camera

## Usage
```
cmake -B build
cmake --build build
```
## Camera movement
| Function | Control |
| -------- | ------- |
| Move Forward  | W / Up Arrow    |
| Move Back | S / Down Arrow     |
| Move Left    | A / Left Arrow    |
| Move Right    | D / Right Arrow    |
| Rotation | Mouse |
